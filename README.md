# Cigar Log App

A simple **Python text-based app** to log and track cigar reviews.  
Keep track of your favorite cigars, rate them, and add notes for future reference. All entries are saved in a JSON file for easy access.

---

## Features
- Add cigars with **name, brand, rating (1–10), and notes**  
- View all cigars logged  
- Stores data in `cigar_log.json` for persistent storage  

---

## Requirements
- Python 3.x installed on your system  
- Basic knowledge of running Python scripts in the terminal
